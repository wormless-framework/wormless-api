# wormless-api

## Stack 

O backend foi construído usando:

*   **Java 21**
*   **Spring Boot 3** (Web, Data JPA)
*   **Spring Cloud OpenFeign** (Integração com a APIs externas)
*   **MySQL 8**
*   **Docker & Docker Compose**
*   **`@Async` (Processamento Assíncrono)** 

---

## Executar Localmente

Suba a infraestrutura usando o Docker Compose: 

```bash
docker compose up --build

```
